# Sloth Story Studio — 品牌素材

本目录是 Sloth Story Studio 的品牌素材包。

## 文件说明
- `app-icon-1024.png` — 高分辨率应用图标源文件
- `app-icon-512.png` — 标准应用图标（侧边栏品牌、配置窗口、Dock 图标）
- `app-icon.icns` — macOS 打包/Dock 专用图标（由 1024px 源图生成）
- `tray-icon.png`、`tray-icon@2x.png` — 菜单栏托盘图标（已内嵌到主进程代码中，此处留档）
- `favicon-32.png`、`favicon-16.png` — 页面小图标
- `sidebar-mark-256.png` — 由品牌参考板提取的透明底单色标志（托盘图标的来源图）
- `sidebar-preview-24.png`、`compact-nav-20.png` — 小尺寸预览图
- `brand-board.png` — 完整视觉概念板（含浅色/深色界面方向）

## 配色
- 陶土红：`#C85B4E`
- 板岩灰：`#7D8796`
- 奶油色：`#F1E6CC`

## 备注
这些素材是从生成的品牌概念板中提取的初版概念稿，并非最终矢量稿。
打包发布时，平台专用图标（macOS `.icns`、Windows `.ico`）由 1024px 源图生成；
单色标志在实际界面尺寸下检视后再定稿。所有原始素材请保留在版本库中。
