# Sloth Story Studio 使用指南

## 入口都在哪

| 要找什么 | 位置 |
|---|---|
| 大模型配置 | ① 主窗口左侧栏底部「大模型配置」 ② macOS 屏幕**右上角菜单栏**的树懒托盘图标 → 大模型配置 |
| 系统设置（目录/背景图） | ① 侧栏底部「设置」 ② 托盘图标 → 系统设置 |
| 风格模板 | 侧栏「工具 → 风格模板」 |
| Agents / 工作流 | 侧栏「工具 → 智能体 / 工作流」 |

> 托盘图标在 macOS 是菜单栏**右上角**（时钟、WiFi 那一排）的小树懒，不是 Dock。

## 第一次用

1. 托盘或侧栏打开「大模型配置」→ 新建：填名称、地址、API Key、model（如 deepseek-chat）→ 测试连接 → 保存。
   - Kimi 订阅类套餐：取消勾选「自定义温度」。
2. 首页新建小说项目（书名、简介）。
3. 侧栏点你的书 → 创作工作台 → 选「极简创作」，直接对 AI 说想写什么。

## 日常写书（极简创作，推荐）

- **每句话 = 写下一章**："写第三章，他去执法堂查契约" → 自动跑流水线、存章节、更新记忆；
- 第一次说话会自动先做全书规划；
- 对话区顶部「每单元章数上限」：留空 = 所有章节在一个单元（适合单线长篇）；设 6-8 = 写满自动复盘归档、开新单元（适合单元剧）；
- 左栏点章节可预览全文。

## 专业模式（进阶）

工作台顶部切「专业模式」：

- **全书规划**：开书时跑一次，产出大纲（进提案区，接受后落库）；
- **规划新单元**：开下一个故事单元；
- **创作章节**：跑章节流水线，支持「连写 N 章」（自动存章+自动记忆）；
- **单元复盘**：单元写完后归档；
- **管理共享记忆**：记忆文件（大纲等）+ 结构化状态（角色/伏笔，可锁定）+ 待审核提案；
- **提取章节记忆**：章节定稿后提取事实进状态库，支持多选批量。

### 推荐节奏

```
全书规划（一次）→ 规划新单元 → 创作章节 × N（每章定稿后提取记忆）→ 单元复盘 → 规划新单元 → …
```

## 章节编辑器

- 四列：单元 | 章节 | 编辑区 | AI 面板；
- 单元/章节：双击或右键重命名，右键删除；
- 编辑区顶部「历史」：版本对比（diff）与回滚——误改误删都能找回；
- AI 面板：直接写 / 多 Agent / 工作流三种生成方式。

## 工作流画布（专家向）

- 节点：Agent / Prompt / 结构化审核 / 局部修订 / 上下文构建 / 备注；
- 连线：双击设置样式与条件（可视化条件编辑器，不用写代码）；
- 顶部「预算」：限制单次运行的调用次数/token/超时，防烧钱；
- 「优化」：用文字描述让 AI 帮你改工作流。

## 数据在哪

| 内容 | 位置 |
|---|---|
| 小说正文、记忆、运行记录 | 设置里的「小说文本目录」 |
| 大模型配置（Key 加密） | 系统应用数据目录 `models.json` |
| Agents / 工作流 / 风格模板 | 各自的自定义目录（设置里可改） |

## 常见问题

- **504 超时**：模型服务商网关超时，重跑即可；失败的运行可在运行记录里「从断点继续」，不重复花钱；
- **Kimi 报 invalid temperature**：该模型配置里取消勾选「自定义温度」；
- **托盘图标找不到**：macOS 菜单栏右上角；实在找不到就用侧栏底部的「大模型配置 / 设置」；
- **改了文件界面没变**：窗口重新聚焦会自动刷新（切走再切回来）。
